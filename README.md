# Matthew Phillips — Technical Portfolio

Static portfolio site with a drafting-table look: vellum paper, blueprint grids, and a hero drawing that sketches itself in.

- `index.html`, `styles.css`, `script.js`: the site (no build step)
- `assets/`: resume PDFs, the CAD portfolio PDF and the original screenshots
- `assets/cad/`: CAD screenshots cropped to the drawing sheet, used in the gallery and lightbox

Preview it by opening `index.html`. To publish, upload the folder to any static host (GitHub Pages, Netlify, Cloudflare Pages).

Site copy follows the October 2026 master applicant profile. Personal project sites, repositories and domains are intentionally never named or linked here.
